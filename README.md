# Interfy API Documentation

- [Open the interactive API reference](https://interfy.github.io/api-docs/)
- [Start with the five-minute integration guide](QUICKSTART.md)

The production server root is `https://api.interfy.io`. Operation paths in the
reference are complete and include `/api/v2`, for example
`POST /api/v2/ecm/documents`.

When using the central server, send the workspace context in `X-Workspace`.
Never put production credentials in a shared Swagger UI session or commit them
to source control.
